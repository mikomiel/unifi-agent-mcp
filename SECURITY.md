# Security

Use [GitHub private vulnerability reporting](https://github.com/mikomiel/unifi-agent-mcp/security/advisories/new) for suspected vulnerabilities. Include the affected version, reproduction steps using synthetic data, and the possible impact. Keep credentials and private controller details out of reports.

Use a dedicated credential for each deployment. Require authentication for change requests. Keep the UniFi write credential accessible only to the executor that applies operator-approved changes.
